## 新功能

### qwen3.8-max 思考等级全路径支持

qwen3.8-max 的推理强度接口只接受 `low`、`medium`、`xhigh` 三个值。主流推理模型（GPT-5 系列、o 系列、Grok Build）都支持的 `high` 在 qwen3.8-max 上会被拒绝。本版在代理的每一条协议转换桥上加入了钳制逻辑，确保发出的请求永远落在这三个值之内。

#### 各 API 格式下的转换规则

| 转换路径 | 来源字段 | 转换行为 |
| --- | --- | --- |
| **Responses API 透传**（Codex / Grok Build 直连） | `reasoning.effort` | 原地钳制：`low` → `low`，`medium` → `medium`，`high` / `xhigh` / `max` → `xhigh` |
| **Codex → Anthropic 格式** | `reasoning.effort` | 不使用 Anthropic 的 `thinking` / `budget_tokens` / `adaptive` 机制；改为输出 `reasoning_effort` + `enable_thinking: true`。`none` / `off` / `disabled` 时不注入任何推理字段 |
| **Claude → Anthropic 透传** | `thinking.type` + `budget_tokens` 或 `output_config.effort` | 先从 Anthropic 格式解析出等级（`budget_tokens` < 4000 → `low`，4000–15999 → `medium`，≥ 16000 → `high`；`adaptive` → `xhigh`），再钳制为 qwen 接受的值，注入 `reasoning_effort` + `enable_thinking: true` |
| **Codex → Chat Completions 格式** | `reasoning.effort` | 新增 `"qwen"` 等级值模式：`minimal` / `low` → `low`，`medium` → `medium`，其余 → `xhigh`。参数名为 `reasoning_effort`，思考开关为 `enable_thinking`，输出格式为 `reasoning_content` |
| **Anthropic → Responses / Chat 格式** | `thinking` / `output_config` | 经 `resolve_reasoning_effort()` 解析后，由 `clamp_reasoning_effort_for_model()` 统一钳制 |

#### 为什么 `high` 映射到 `xhigh` 而不是 `medium`

`high` 在其它模型上的语义是「扩展推理」——比默认更深的思考。qwen3.8-max 没有 `high` 这个档位，而 `xhigh` 正是它的最强推理等级，语义最接近。把 `high` 降为 `medium` 会削弱用户明确请求的推理深度。

#### 对其它模型无影响

钳制函数按模型名前缀匹配 `qwen3.8-max`，对其它所有模型（GPT-5、o 系列、Grok Build、Claude 等）是原样透传，不改变任何既有行为。

## 风险提示

### 沿用的提示

**xAI Grok OAuth 登录**：复用官方 Grok CLI 的公开 OAuth 客户端身份，使用可能导致账号被限制或封禁——详见 [v3.18.0 release notes](v3.18.0-zh.md#风险提示)。

**Codex OAuth 反向代理**：使用 ChatGPT 订阅的 Codex OAuth 反代可能违反 OpenAI 服务条款，详情见 [v3.13.0 release notes](v3.13.0-zh.md#️-风险提示)。

**第三方供应商路由**：通过 CC Switch 本地代理把 Codex、Claude Desktop 或 Grok Build 的请求转换并转发到第三方供应商时，各供应商对计费、合规与数据留存的约束不同，请在使用前阅读目标供应商的服务条款。

用户启用上述功能即表示自行承担相关风险。CC Switch 不对因使用这些功能而导致的任何账号限制、警告或服务暂停承担责任。

## 下载与安装

访问 [Releases](https://github.com/farion1231/cc-switch/releases/latest) 下载对应版本，或从官网 [ccswitch.io](https://ccswitch.io) 获取（下载经 Cloudflare 边缘节点分发，不依赖 GitHub 可达）。

### 系统要求

| 系统    | 最低版本                   | 架构                                |
| ------- | -------------------------- | ----------------------------------- |
| Windows | Windows 10 及以上          | x64 / ARM64                         |
| macOS   | macOS 12 (Monterey) 及以上 | Intel (x64) / Apple Silicon (arm64) |
| Linux   | 见下表                     | x64 / ARM64                         |

### Windows

| 文件                                     | 说明                                |
| ---------------------------------------- | ----------------------------------- |
| `CC-Switch-v3.19.2-Windows.msi`          | **推荐** - MSI 安装包，支持自动更新 |
| `CC-Switch-v3.19.2-Windows-Portable.zip` | 便携版，解压即用，不写入注册表      |

Windows ARM64 设备请选择文件名中带 `arm64` 标识的对应制品。

### macOS

| 文件                             | 说明                                          |
| -------------------------------- | --------------------------------------------- |
| `CC-Switch-v3.19.2-macOS.dmg`    | **推荐** - DMG 安装包，拖入 Applications 即可 |
| `CC-Switch-v3.19.2-macOS.zip`    | 解压后拖入 Applications，Universal Binary     |
| `CC-Switch-v3.19.2-macOS.tar.gz` | 用于 Homebrew 安装和自动更新                  |


```bash

```

- `CC-Switch-v3.19.2-Linux-x86_64.AppImage` / `.deb` / `.rpm`
