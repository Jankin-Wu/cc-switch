# CC Switch v3.19.2

> 本リリースが行うことは 1 つだけです：**qwen3.8-max シリーズが、ローカルプロキシのすべてのプロトコル変換経路で推論レベルを正しく伝えられるようにすること**。qwen3.8-max の推論強度は 3 つの値——`low`・`medium`・`xhigh`——しか受け付けず、他の多くの推論モデルがサポートする `high` を**拒否します**。本リリースでは、プロキシの各変換ブリッジにクランプ処理を追加し、`high` 以上のレベルをすべて `xhigh` に統一マッピングします。`low` と `medium` はそのまま通過します。

## 追加機能

### qwen3.8-max の推論レベルをすべてのプロキシ経路でサポート

qwen3.8-max の推論強度インターフェースは `low`・`medium`・`xhigh` の 3 つの値しか受け付けません。主要な推論モデル（GPT-5 シリーズ、o シリーズ、Grok Build）がサポートする `high` は、qwen3.8-max では拒否されます。本リリースでは、プロキシの各プロトコル変換ブリッジにクランプロジックを追加し、送信されるリクエストが常にこの 3 つの値の範囲内に収まるようにしました。

#### API 形式ごとの変換ルール

| 変換経路 | ソースフィールド | 変換の動作 |
| --- | --- | --- |
| **Responses API パススルー**（Codex / Grok Build 直接接続） | `reasoning.effort` | その場でクランプ：`low` → `low`、`medium` → `medium`、`high` / `xhigh` / `max` → `xhigh` |
| **Codex → Anthropic 形式** | `reasoning.effort` | Anthropic の `thinking` / `budget_tokens` / `adaptive` の仕組みを完全にバイパスし、代わりに `reasoning_effort` + `enable_thinking: true` を出力します。`none` / `off` / `disabled` の場合は推論フィールドを一切注入しません |
| **Claude → Anthropic パススルー** | `thinking.type` + `budget_tokens` または `output_config.effort` | Anthropic 形式からレベルを解決し（`budget_tokens` < 4000 → `low`、4000–15999 → `medium`、≥ 16000 → `high`、`adaptive` → `xhigh`）、qwen が受け付ける値にクランプしてから `reasoning_effort` + `enable_thinking: true` を注入します |
| **Codex → Chat Completions 形式** | `reasoning.effort` | 新しい `"qwen"` レベル値モード：`minimal` / `low` → `low`、`medium` → `medium`、その他 → `xhigh`。パラメータ名は `reasoning_effort`、思考のスイッチは `enable_thinking`、出力形式は `reasoning_content` |
| **Anthropic → Responses / Chat 形式** | `thinking` / `output_config` | `resolve_reasoning_effort()` で解決した後、`clamp_reasoning_effort_for_model()` で統一的にクランプします |

#### なぜ `high` を `medium` ではなく `xhigh` にマッピングするのか

他のモデルにおける `high` の意味は「拡張推論」——デフォルトより深い思考です。qwen3.8-max には `high` の段階がなく、`xhigh` が最も強い推論レベルであり、意味的に最も近いです。`high` を `medium` に下げることは、ユーザーが明示的に要求した推論の深さを黙って弱めることになります。

#### 他のモデルへの影響はありません

クランプ関数はモデル名のプレフィックス `qwen3.8-max` で照合します。他のすべてのモデルファミリー（GPT-5、o シリーズ、Grok Build、Claude など）にはそのまま通過し、既存の動作は一切変わりません。

## アップグレード時の注意

- 本リリースに**データベースマイグレーションはありません**——アップグレード後すぐに利用できます。
- 推論レベルのクランプはローカルプロキシ層でのみ有効です。ローカルルーティングなしで直接接続しているプロバイダは影響を受けません。
- 保存済みのプロバイダ設定に変更は不要です——リクエストがプロキシを通る限り、クランプは自動的に適用されます。

## ダウンロードとインストール

[Releases](https://github.com/farion1231/cc-switch/releases/latest) から、お使いのシステムに対応するビルドをダウンロードするか、公式サイト [ccswitch.io](https://ccswitch.io) から入手してください（ダウンロードは Cloudflare のエッジノード経由で配信され、GitHub への到達性に依存しません）。

### システム要件

| システム | 最低バージョン           | アーキテクチャ                      |
| -------- | ------------------------ | ----------------------------------- |
| Windows  | Windows 10 以降          | x64 / ARM64                         |
| macOS    | macOS 12 (Monterey) 以降 | Intel (x64) / Apple Silicon (arm64) |
| Linux    | 下表を参照               | x64 / ARM64                         |

### Windows

| ファイル                                 | 説明                                         |
| ---------------------------------------- | -------------------------------------------- |
| `CC-Switch-v3.19.2-Windows.msi`          | **推奨** - 自動更新対応の MSI インストーラー |
| `CC-Switch-v3.19.2-Windows-Portable.zip` | ポータブル版、展開してそのまま実行できます   |

Windows ARM64 デバイスでは、ファイル名に `arm64` が含まれる対応する成果物を選択してください。

### macOS

| ファイル                         | 説明                                                   |
| -------------------------------- | ------------------------------------------------------ |
| `CC-Switch-v3.19.2-macOS.dmg`    | **推奨** - DMG インストーラー、Applications へドラッグ |
| `CC-Switch-v3.19.2-macOS.zip`    | 展開して Applications へドラッグ、Universal Binary     |
| `CC-Switch-v3.19.2-macOS.tar.gz` | Homebrew インストールと自動更新用                      |

Homebrew インストール：

```bash
brew install --cask cc-switch
```

更新：

```bash
brew upgrade --cask cc-switch
```

### Linux

Linux アセットは **x86_64** と **ARM64**（`aarch64`）の両方を提供します。ファイル名のアーキテクチャ識別子を、マシンの `uname -m` 出力に合わせて選択してください：

- `CC-Switch-v3.19.2-Linux-x86_64.AppImage` / `.deb` / `.rpm`
- `CC-Switch-v3.19.2-Linux-arm64.AppImage` / `.deb` / `.rpm`

| ディストリビューション                  | 推奨形式    | インストール方法                                                           |
| --------------------------------------- | ----------- | -------------------------------------------------------------------------- |
| Ubuntu / Debian / Linux Mint / Pop!\_OS | `.deb`      | `sudo dpkg -i CC-Switch-*.deb` または `sudo apt install ./CC-Switch-*.deb` |
| Fedora / RHEL / CentOS / Rocky Linux    | `.rpm`      | `sudo rpm -i CC-Switch-*.rpm` または `sudo dnf install ./CC-Switch-*.rpm`  |
| openSUSE                                | `.rpm`      | `sudo zypper install ./CC-Switch-*.rpm`                                    |
| Arch Linux / Manjaro                    | `.AppImage` | 実行権限を付与して直接実行、または AUR を利用                              |
| その他 / 不明な場合                     | `.AppImage` | `chmod +x CC-Switch-*.AppImage && ./CC-Switch-*.AppImage`                  |
