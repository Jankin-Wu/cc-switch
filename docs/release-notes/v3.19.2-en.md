# CC Switch v3.19.2

> This release does one thing: **give the qwen3.8-max family correct reasoning-effort translation on every protocol conversion path the local proxy implements**. qwen3.8-max accepts only three effort levels — `low`, `medium`, `xhigh` — and **rejects** the `high` value that most other reasoning models understand. Every conversion bridge in the proxy now clamps `high` (and anything above `medium` that is not already `xhigh`) to `xhigh`; `low` and `medium` pass through unchanged.

## Added

### qwen3.8-max Reasoning Effort Across All Proxy Paths

qwen3.8-max's reasoning interface accepts only `low`, `medium`, and `xhigh`. The `high` value supported by mainstream reasoning models (GPT-5 series, o-series, Grok Build) is rejected by qwen3.8-max. This release adds clamping logic on every protocol conversion bridge in the proxy, ensuring outgoing requests always land within the three accepted values.

#### Conversion Rules by API Format

| Conversion Path | Source Field | Behavior |
| --- | --- | --- |
| **Responses API passthrough** (Codex / Grok Build direct) | `reasoning.effort` | Clamped in place: `low` → `low`, `medium` → `medium`, `high` / `xhigh` / `max` → `xhigh` |
| **Codex → Anthropic format** | `reasoning.effort` | Bypasses Anthropic's `thinking` / `budget_tokens` / `adaptive` machinery entirely; emits `reasoning_effort` + `enable_thinking: true` instead. `none` / `off` / `disabled` suppresses all reasoning fields |
| **Claude → Anthropic passthrough** | `thinking.type` + `budget_tokens` or `output_config.effort` | Resolves effort from the Anthropic format (`budget_tokens` < 4000 → `low`, 4000–15999 → `medium`, ≥ 16000 → `high`; `adaptive` → `xhigh`), then clamps to qwen's accepted values and injects `reasoning_effort` + `enable_thinking: true` |
| **Codex → Chat Completions format** | `reasoning.effort` | New `"qwen"` effort-value mode: `minimal` / `low` → `low`, `medium` → `medium`, everything else → `xhigh`. Parameter name is `reasoning_effort`, thinking toggle is `enable_thinking`, output format is `reasoning_content` |
| **Anthropic → Responses / Chat format** | `thinking` / `output_config` | Resolved via `resolve_reasoning_effort()`, then uniformly clamped by `clamp_reasoning_effort_for_model()` |

#### Why `high` Maps to `xhigh` Rather Than `medium`

On other models, `high` semantically means "extended reasoning" — deeper thinking than the default. qwen3.8-max has no `high` tier; its strongest reasoning level is `xhigh`, which is the closest semantic equivalent. Downgrading `high` to `medium` would silently reduce the reasoning depth the user explicitly requested.

#### No Impact on Other Models

The clamping function matches on the `qwen3.8-max` model-name prefix. For every other model family (GPT-5, o-series, Grok Build, Claude, etc.) it is a no-op passthrough that preserves all existing behavior.

## Upgrade Notes

- This release has **no database migration** — upgrade and use immediately.
- Effort clamping takes effect only at the local proxy layer; providers connected directly without local routing are unaffected.
- No changes to saved provider configurations are needed — clamping applies automatically as long as requests pass through the proxy.
